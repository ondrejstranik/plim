# Plim

[![GitHub](https://img.shields.io/badge/GitHub-ondrejstranik%2Fplim-blue?logo=github)](https://github.com/ondrejstranik/plim)

Plim is a package for plasmon imaging: acquiring, viewing, and fitting the
kinetic binding signals from plasmonic-spot sensor arrays (e.g. SPR/LSPR).

It builds on [Viscope](https://ondrejstranik.github.io/viscope/) for
instrument control -- so acquisition GUIs can drive either a real
spectral camera / pump setup or a fully virtual one -- and on
[spectralCamera](https://github.com/ondrejstranik/spectralCamera) for
spectral-image acquisition and calibration.

See [Installation](installation.md) for setup instructions and
[Examples](examples.md) for how to run the signal analyser.
